# Атлас Познания — Кабинет Исследователя

Адаптивный сайт-приложение, собранный на HTML, CSS и JavaScript. Восемь экранов используют исходные изображения макета; интерактивные кнопки размещены прозрачными HTML-областями поверх изображений.

## Сайт

GitHub Pages: https://romanketer.github.io/Test_1_orakl/

Публикация выполняется из ветки `main`, корня репозитория. Сборщик и backend для демонстрационной версии не нужны.

## Возможности демонстрационной версии

- **Навигация:** восемь исходных экранов, переходы между разделами, меню, возврат назад и история браузера.
- **Таро:** учебная библиотека арканов, значения и символика, сохранение заметок, демонстрационные расклады, конструктор собственных позиций, мини-экзамен и выбор учебной колоды.
- **Астрология:** сохранение исходных данных рождения, демонстрационные вкладки натала/транзитов/прогноза/синастрии, профили для сравнения, справочные материалы по домам и аспектам, список мест для релокации.
- **Психология:** чек-листы самонаблюдения, вкладки по отношениям и практикам, учебный тест, упражнения, дневник эмоций, шаблон записи автоматической мысли, справочник когнитивных искажений и личные цели.
- **Сновидения:** создание, редактирование и удаление записей, символы и эмоции, поиск по словарю образов, подсчёт повторяющихся символов и вопросы для самостоятельного осмысления.
- **Арена знаний:** локальная демонстрация дуэли, сохранение ответа, учебные вкладки турнира/лиги/гильдий, рейтинг, история и правила.
- **Дополнительные направления:** учебные кейсы профайлинга, переформулирование фраз NLP, демонстрационный нумерологический расчёт и журнал междисциплинарных исследований.
- **Темы:** выбор одной из шести цветовых тем с сохранением настройки.

## Хранение данных и ограничения

Записи и настройки хранятся в `localStorage` текущего браузера на текущем устройстве. Данные не синхронизируются с другими устройствами и не имеют облачной резервной копии. Очистка данных сайта в браузере удалит эти локальные записи.

Это демонстрационная версия без регистрации, backend и сетевого сообщества. Арена не подключает реальных соперников и не оценивает качество трактовки: она сохраняет написанный ответ и показывает только его длину. Натальная карта, транзиты, синастрия и релокация не рассчитываются по эфемеридам или географическим координатам — формы и материалы показывают структуру будущих инструментов. Нумерологический экран демонстрирует сумму цифр даты, а не научную оценку личности. Психологические упражнения предназначены для самонаблюдения и не являются диагностикой.

## Структура проекта

| Файл | Назначение |
|---|---|
| `index.html` | Оболочка сайта, меню, рабочая область и диалоговые окна |
| `style.css` | Адаптивная компоновка и стили интерактивных модулей |
| `app.js` | Навигация, интерактивные сценарии, формы, локальное хранение и работа с изображениями |
| `functional-data.js` | Временный каталог учебных карточек, вопросов, упражнений, символов и тем |
| `atlas-reference-assets.zip` | Восемь изображений WebP из исходного макета; загружаются и распаковываются в браузере |
| `PROJECT_STATUS.md` | Постоянный журнал проекта и инструкция по восстановлению работы после перезапуска |
| `tests/verify-layout.mjs` | Playwright-проверки восьми экранов, адаптивности, переходов, истории и базовой навигации |
| `tests/verify-functionality.mjs` | Playwright-проверки форм, учебных сценариев, дневников, тем и локального сохранения |
| `.github/workflows/atlas-ui.yml` | Автоматический запуск браузерных проверок и создание скриншотов |

`app-data.js` — оставшийся ранний файл с исходным описанием областей интерфейса. Текущая страница его не подключает; рабочий каталог временных данных — `functional-data.js`.

## Адаптивность

- **До 699 px:** полноэкранный портретный экран из исходного макета.
- **700–1099 px:** компактная боковая навигация и центральный экран.
- **От 1100 px:** боковая навигация, центральный экран и дополнительная контекстная панель.

## Проверки

Запуск тестов выполняется GitHub Actions при каждом push в `main` и при pull request в `main`. В workflow запускаются:

```bash
node tests/verify-layout.mjs
node tests/verify-functionality.mjs
```

Тесты используют Playwright и Chromium. Они проверяют мобильный, планшетный и настольный размеры окна, загрузку всех восьми экранов, переходы и основные пользовательские сценарии. Скриншоты desktop/tablet/mobile сохраняются как артефакт workflow.

## Работа над проектом

Перед продолжением разработки сначала прочитайте `PROJECT_STATUS.md`, проверьте актуальный HEAD ветки `main` и последние GitHub Actions runs. После каждого этапа обновляйте журнал, фиксируйте успешный коммит и останавливайтесь до следующей команды пользователя.
