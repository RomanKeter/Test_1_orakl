# Атлас Познания

Адаптивный интерактивный прототип по исходному визуальному макету.

## Визуальная основа

Восемь экранов используют оригинальные иллюстрации из `atlas-reference-assets.zip`. Архив должен лежать в корне репозитория рядом с `index.html`; приложение читает его в браузере, извлекает WebP-изображения и накладывает на них прозрачные интерактивные области. Это сохраняет исходную композицию, рисунки, фактуру бумаги, подписи и кнопки.

## Структура

- `index.html` — контейнер приложения и системные слои;
- `app-data.js` — данные экранов, координаты интерактивных областей и тексты демо;
- `app.js` — навигация, загрузка исходных изображений и поведение элементов;
- `style.css` — адаптивная оболочка, меню и модальные окна;
- `atlas-reference-assets.zip` — восемь оригинальных экранов в WebP.

## Что работает в демо

- восемь экранов: главная, карта исследований, Таро, астрология, психология, сновидения, арена знаний и темы оформления;
- переходы по экранным кнопкам, меню и возврат назад;
- учебные модальные окна, демонстрационная дуэль и выбор темы;
- переключатели самонаблюдения;
- локальный дневник заметок и сновидений через хранилище браузера.

Данные и содержимое модальных окон временные. Записи хранятся только в текущем браузере и на текущем устройстве.

## Локальный запуск

Из корня проекта выполните:

```bash
python3 -m http.server 8000
```

Затем откройте `http://localhost:8000/`. Для ZIP-архива нужен HTTP-сервер; открытие `index.html` напрямую через `file://` не поддерживается.

## GitHub Pages

Для публикации выберите ветку `main` и папку `/ (root)` в настройках GitHub Pages.
