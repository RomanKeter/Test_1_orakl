# Атлас Познания — Кабинет Исследователя

Адаптивный статический сайт на HTML, CSS и JavaScript. Визуальная основа восьми экранов использует изображения из исходного макета, а интерактивность реализована прозрачными HTML-кнопками поверх изображения.

## Запуск
GitHub Pages публикует проект из ветки main, корня репозитория (/). Дополнительная сборка или серверная часть не требуются.

## Файлы
- index.html — оболочка приложения, навигационные панели и диалоги.
- style.css — адаптация для телефона, планшета, ноутбука и широкого монитора.
- app.js — загрузка исходных экранов, интерактивные области и переходы.
- atlas-reference-assets.zip — восемь исходных WebP-экранов в папке assets/.

## Адаптивность
- До 699 px: оригинальная полноэкранная мобильная компоновка.
- 700–1099 px: навигация слева и центральный экран.
- От 1100 px: навигация слева, центральный экран и информационная панель справа.

Изображения сохраняют пропорции исходного макета. На широком экране центральный экран ограничен по высоте и при необходимости прокручивается отдельно.
