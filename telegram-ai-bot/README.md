# Telegram AI Bot — этап 1

Первая версия персонального Telegram-бота с ИИ. Бот общается в личной переписке, хранит историю пользователя в SQLite, позволяет менять стиль общения и сохранять исправления.

## Что уже умеет

- Отвечать через OpenAI Responses API.
- Хранить отдельную историю для каждого Telegram-пользователя.
- Использовать последние сообщения как контекст диалога.
- Менять индивидуальную настройку личности командой `/persona`.
- Добавлять постоянные правила командой `/teach`.
- Показывать правила командой `/rules`.
- Сохранять исправление последнего ответа командой `/correct`.
- Удалять историю и настройки командой `/forget`.

На первом этапе бот работает только в личной переписке. Групповые чаты, отдельные профили участников групп, коллективная память и панель управления запланированы на этап 2.

## 1. Что потребуется

1. Python 3.11 или новее.
2. Telegram-бот, созданный через [@BotFather](https://t.me/BotFather).
3. API-ключ OpenAI с включённым биллингом API. Подписка ChatGPT сама по себе не включает оплату API.

## 2. Установка на Debian 13

Открой терминал и выполни:

```bash
sudo apt update
sudo apt install -y python3 python3-venv python3-pip git
git clone https://github.com/RomanKeter/Test_1_orakl.git
cd Test_1_orakl/telegram-ai-bot
python3 -m venv .venv
source .venv/bin/activate
pip install --upgrade pip
pip install -r requirements.txt
```

Если репозиторий уже клонирован, повторно выполнять `git clone` не нужно: перейди в папку проекта.

## 3. Настройка ключей

Создай локальный файл настроек:

```bash
cp .env.example .env
nano .env
```

Заполни:

- `TELEGRAM_BOT_TOKEN` — токен, который выдаст @BotFather.
- `OPENAI_API_KEY` — API-ключ из кабинета OpenAI.
- `OPENAI_MODEL` — модель для ответов. По умолчанию указана `gpt-4.1-mini`.

Не отправляй токены в чат и не добавляй настоящий файл `.env` в GitHub. Он исключён через `.gitignore`.

## 4. Запуск

```bash
source .venv/bin/activate
python bot.py
```

Оставь терминал открытым. Найди своего бота в Telegram и отправь ему `/start`.

Остановка: `Ctrl+C`.

## 5. Как задавать характер

Примеры команд в Telegram:

```text
/persona Ты спокойный, самостоятельный и критически мыслящий бизнес-ассистент. Не соглашайся автоматически. Объясняй риски и предлагай альтернативы.
/teach Перед выводами отделяй подтверждённые факты от предположений.
/teach Если задача неоднозначна, сначала задай один самый важный уточняющий вопрос.
/rules
```

Команда `/persona` задаёт общую индивидуальную настройку. Команда `/teach` добавляет отдельное правило, которое будет применяться в последующих ответах.

## 6. Как исправлять ответы

Если ответ не понравился, отправь:

```text
/correct Ты сделал вывод без достаточных данных. Сначала перечисли, что известно, затем укажи, чего не хватает, и только потом делай вывод.
```

Исправление сохраняется в таблице обучающих примеров вместе с исходным ответом. В версии этапа 1 примеры не меняют личность автоматически: это сделано намеренно, чтобы случайная коррекция не испортила правила. На этапе 2 добавим просмотр, подтверждение и превращение исправлений в устойчивые правила.

## 7. Где хранятся данные

По умолчанию локальная база: `data/bot.sqlite3`. Она создаётся автоматически при запуске. В ней находятся история, настройки личности, правила и исправления.

Не удаляй файл базы, если хочешь сохранить историю. Сделай резервную копию перед переносом бота на другой компьютер.

## Ограничения этапа 1

- Пока поддерживаются только личные чаты.
- SQLite подходит для первого запуска на одном экземпляре бота; для групповой и многопользовательской эксплуатации на этапе 2/3 архитектура будет расширена.
- История контекста ограничена последними 12 сообщениями.
- Команда `/forget` удаляет сохранённые данные пользователя из локальной базы.
- Бот не обучает веса нейросети. Он адаптирует ответы с помощью системной инструкции, сохранённых правил, истории и примеров. Это проще контролировать и корректировать.
