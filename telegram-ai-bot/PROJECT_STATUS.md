Этот файл — постоянный журнал проекта. В начале каждой следующей сессии сначала прочитать его, проверить актуальную ветку и последние коммиты, затем продолжать только незавершённые пункты. Не начинать следующий этап без явной команды пользователя.

## Цель

Создать управляемого Telegram ИИ-бота для бизнес-задач. Пользователь должен иметь возможность задавать характер бота, корректировать ответы, сохранять правила, а позднее — использовать персональную и групповую память участников.

## Принятые требования

- Назначение: бизнес-ассистент с возможностью дальнейшей специализации.
- Стиль: пользователь самостоятельно задаёт характер и правила.
- Обучение: через исправления ответов и явное добавление правил.
- Платформа: Telegram.
- Разработка: Python; сначала локальный запуск на Debian 13, затем подготовка к VPS.
- ИИ: OpenAI API.
- Секреты: только локальный `.env`, никогда не коммитить токены.
- Проект должен развиваться в три этапа. После завершения каждого этапа остановиться и дождаться команды пользователя.
